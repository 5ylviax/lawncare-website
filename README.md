# lawncare-website
A full stack web application for a lawn care business.

## Tech Stack

| Layer | Technology |
|---|---|
| **Backend** | Go |
| **Frontend** | HTML, CSS, JavaScript |
| **Database** | SQLite |
| **Hosting** | Render / Azure App Service |
| **Task Runner** | Makefile|


## RUN
```bash 
git clone https://github.com/5ylviax/lawncare-website
cd lawncare-website
cp .env.example .env

## Fill in .env values
make up
```
